# Changelog

## 0.1.0

Initial public-ready release.

- Convert YummySoup! SQLite database to Paprika 3 JSON/GZIP recipe files.
- Package generated recipes into `.paprikarecipes` ZIP archives.
- Support main and secondary photos.
- Convert YummySoup image markers like `[2]` to Paprika markers like `[photo:2]`.
- Normalize bold numbered directions for Paprika's Markdown parser.
